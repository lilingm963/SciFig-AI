# SciFig

[English](README.md) · [中文](README.zh.md) · [Français](README.fr.md) · [Español](README.es.md) · [Italiano](README.it.md) · [Deutsch](README.de.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

## アイデア、データ、研究の流れをわかりやすく図に。

SciFig は Illustration、DataChart、FlowChart を一つの科学コミュニケーションプラットフォームにまとめています。制作の流れを知り、作例を試し、公開リソースを活用できます。

[SciFig を開く](https://scifig.ai/ja/?ref=github-resources) · [すべてのチュートリアルを見る](https://scifig.ai/ja/tutorials?ref=github-resources) · [公式メディアライブラリ](docs/media-library.ja.md)

## 3つのワークスペース

### Illustration

説明や参考資料から科学イラストを作成し、利用できる編集ツールで仕上げます。

[![Illustration の制作工程](assets/previews/illustration.jpg)](https://cdn.scifig.ai/images/media-kit/2026-10/videos/v4-illustration-tutorial.mp4)

[制作の全工程を見る](https://cdn.scifig.ai/images/media-kit/2026-10/videos/v4-illustration-tutorial.mp4) · [すべてのチュートリアルを見る](https://scifig.ai/ja/tutorials?ref=github-resources)

### DataChart

表形式のデータからグラフを作成し、見せ方を調整します。数値、単位、軸、凡例を元データと照合してください。

[![DataChart の制作工程](assets/previews/datachart.jpg)](https://cdn.scifig.ai/images/media-kit/2026-10/videos/v4-datachart-tutorial.mp4)

[制作の全工程を見る](https://cdn.scifig.ai/images/media-kit/2026-10/videos/v4-datachart-tutorial.mp4) · [すべてのチュートリアルを見る](https://scifig.ai/ja/tutorials?ref=github-resources)

### FlowChart

研究プロセスや構造化された手順を図にし、エディターでノードと関係を調整します。

[![FlowChart の制作工程](assets/previews/flowchart.jpg)](https://cdn.scifig.ai/images/media-kit/2026-10/videos/v4-flowchart-tutorial.mp4)

[制作の全工程を見る](https://cdn.scifig.ai/images/media-kit/2026-10/videos/v4-flowchart-tutorial.mp4) · [すべてのチュートリアルを見る](https://scifig.ai/ja/tutorials?ref=github-resources)

共有する前に科学的な意味、ラベル、出典を確認してください。編集・書き出しの選択肢はワークスペースや制作手順によって異なります。チュートリアルで具体例をご覧ください。

## 公開リソース

### ポスター・プレゼンテーション用テンプレート

印刷サイズや発表の目的に応じて154点の PPTX を探せます。レイアウトを確認し、利用前にテンプレートのライセンスをお読みください。

[ポスター・プレゼンテーション用テンプレート](https://github.com/scifig-ai/scientific-poster-and-presentation-templates)

### 科学図表制作 Skill

エージェントで図の構成とプロンプトを準備します。生成には利用可能な画像ツールか設定済みの画像 API を使います。この Skill は SciFig API を呼び出しません。

[科学図表制作 Skill](https://github.com/lilingm963/scifig-ai-scientific-figure-skill)

### 公式メディアライブラリ

完成動画35本、各言語の素材パック、字幕、製品プレビューをまとめています。ファイルは公式 CDN に置き、このリポジトリで一覧と利用案内を提供します。

[公式メディアライブラリ](docs/media-library.ja.md)

## SciFig の開発者

Alex Carter は SciFig の創設者であり、独立系開発者です。プラットフォーム、研究用ポスターと発表テンプレート、実用ガイド、このリソース集を公開しています。編集方針と連絡先は開発者紹介ページをご覧ください。

[開発者紹介と編集方針](https://scifig.ai/ja/about?ref=github-resources)

## ライセンスと利用について

SciFig は商用プラットフォームです。このリポジトリは公開リソースの入口であり、製品のソースコードではありません。素材、テンプレート、MIT ライセンスの Skill はそれぞれ別の条件で提供され、他の内容に自動的には適用されません。

[メディア素材の利用条件](https://scifig.ai/ja/media-kit?ref=github-resources#usage) · [MIT](https://github.com/lilingm963/scifig-ai-scientific-figure-skill/blob/main/LICENSE) · [ポスター・プレゼンテーション用テンプレート](https://github.com/scifig-ai/scientific-poster-and-presentation-templates/blob/main/LICENSE)
