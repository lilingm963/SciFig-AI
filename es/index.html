Tres espacios de trabajo

Illustration

Convierte descripciones y referencias en ilustraciones científicas y afina el resultado con las herramientas de edición disponibles.

DataChart

Crea gráficos a partir de tablas y ajusta su presentación. Contrasta valores, unidades, ejes y leyendas con los datos originales.

Recursos públicos

Plantillas de pósteres y presentaciones

Explora 154 archivos PPTX por tamaño de impresión o tipo de presentación. Previsualiza los diseños y consulta la licencia antes de usarlos.

Skill para figuras científicas

Organiza una figura y prepara prompts en un agente. La generación usa su herramienta de imagen o tu API configurada; este Skill no llama a una API de SciFig.

Biblioteca multimedia oficial

35 vídeos finales, paquetes localizados, subtítulos y vistas previas del producto. Los archivos permanecen en el CDN oficial; este repositorio ofrece el catálogo y las instrucciones de uso.

Quién está detrás de SciFig

Alex Carter es el fundador y desarrollador independiente de SciFig. Su trabajo público incluye la plataforma, plantillas de pósteres y presentaciones científicas, guías prácticas y esta colección. Consulta la página Acerca de para conocer los criterios editoriales y los datos de contacto.

Licencias y uso

SciFig es una plataforma comercial. Este repositorio reúne recursos públicos, no el código del producto. Los materiales, las plantillas y el Skill con licencia MIT tienen términos distintos; ninguna licencia se aplica automáticamente a los demás contenidos.

Condiciones de uso de los materiales

Abre una issue para corregir recursos o solicitar mejoras. No publiques datos privados de investigación ni datos de tu cuenta. Para ayuda con la cuenta, usa la página de contacto oficial.
