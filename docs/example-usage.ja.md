# ライセンスと利用について

入力は学習用に作成した架空の例であり、実験の証拠ではありません。チュートリアルのプレビューは別の制作手順を示しており、これらの入力から生成した結果ではありません。

このディレクトリの架空の CSV とプロンプトは、学習、教育、デモのためにコピー・改変できます。架空の作例であることを明記してください。この許可は入力のみに適用されます。リンク先の動画、ブランド素材、テンプレート、Skill にはそれぞれの条件が適用されます。

[メディア素材の利用条件](https://scifig.ai/ja/media-kit?ref=github-resources)

SciFig は商用プラットフォームです。このリポジトリは公開リソースの入口であり、製品のソースコードではありません。素材、テンプレート、MIT ライセンスの Skill はそれぞれ別の条件で提供され、他の内容に自動的には適用されません。
