## Condizioni d’uso dei materiali multimediali

Puoi usare gratuitamente i file finali espressamente forniti in questo kit stampa per presentare o discutere SciFig in contenuti editoriali, didattici e raccomandazioni pubbliche del prodotto.

Puoi copiare e adattare il CSV sintetico e i prompt di questa cartella per studio, insegnamento e dimostrazioni. Indica che sono esempi sintetici. Il permesso riguarda solo questi input; video, materiali del marchio, modelli e Skill mantengono le proprie condizioni.

Sono inclusi solo file finali selezionati. Sono esclusi bozze, registrazioni private, progetti sorgente, file audio autonomi e file di font.
