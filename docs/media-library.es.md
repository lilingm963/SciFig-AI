## Condiciones de uso de los materiales

Puedes utilizar gratuitamente los archivos finales ofrecidos expresamente en este kit de prensa para presentar o comentar SciFig en contenidos editoriales, educativos y recomendaciones públicas del producto.

Puedes copiar y adaptar el CSV sintético y los prompts de este directorio para aprendizaje, enseñanza y demostraciones. Identifícalos como ejemplos sintéticos. Este permiso solo cubre estas entradas; los vídeos, materiales de marca, plantillas y Skill mantienen sus propios términos.

Solo se incluyen archivos finales seleccionados. Quedan excluidos borradores, grabaciones privadas, proyectos originales, archivos de audio independientes y archivos de fuentes.
