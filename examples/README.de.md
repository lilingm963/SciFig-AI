## Konzeptionelle Probenvorbereitung · Illustration

### Eingabe

Erstellen Sie eine konzeptionelle Illustration mit drei beschrifteten Feldern: Probe entnehmen, Probe vorbereiten, Probe beobachten. Weißer Hintergrund, Blau-Grün-Palette, klare Pfeile von links nach rechts. Erfinden Sie keine Geräte, Werte oder biologischen Mechanismen. Kennzeichnen Sie sie als „konzeptionelles Lehrbeispiel“.

### Schritte und Prüfungen

Verwenden Sie den Prompt in Illustration. Prüfen Sie Beschriftungen und Pfeilrichtungen und probieren Sie ein Werkzeug aus dem Tutorial aus. Das Beispiel beschreibt kein reales Versuchsprotokoll.

## Synthetische Messwerte im Zeitverlauf · DataChart

### Eingabe

### Schritte und Prüfungen

Laden Sie die CSV in DataChart hoch. Zeichnen Sie signal_a und signal_b als zwei Reihen über time_min. Beschriften Sie die vertikale Achse mit „willkürliche Einheiten“ und vergleichen Sie jeden Punkt mit der CSV. Prüfen Sie die Legende und nutzen Sie die verfügbaren Exportoptionen.

## Ein Lehrbeispiel zur Datenprüfung · FlowChart

### Eingabe

Erstellen Sie einen Lehrablauf: synthetischen Datensatz empfangen → Spaltennamen und Einheiten prüfen → fehlende Werte prüfen → zusammenfassen → Diagramm prüfen → teilen. Bei fehlgeschlagener Validierung zur Eingabe zurückkehren. Beschriften Sie die Zweige und behalten Sie die Prüfung vor dem Teilen bei.

### Schritte und Prüfungen

Verwenden Sie den Text in FlowChart. Prüfen Sie alle Knoten, die Validierungsschleife und Entscheidungsbeschriftungen. Ändern Sie einen Knoten im Editor und prüfen Sie, ob die Beziehungen weiterhin der Eingabe entsprechen.

[Den vollständigen Ablauf ansehen](https://cdn.scifig.ai/images/media-kit/2026-10/videos/v4-flowchart-tutorial.mp4)

Prüfen Sie vor dem Teilen die wissenschaftliche Bedeutung, Beschriftungen und Quellen. Bearbeitung und Export hängen vom Arbeitsbereich und Ablauf ab; die Tutorials zeigen konkrete Beispiele.
