## Preparación conceptual de muestras · Illustration

### Entrada

Crea una ilustración conceptual con tres paneles etiquetados: recoger muestra, preparar muestra, observar muestra. Fondo blanco, paleta azul y verde, flechas claras de izquierda a derecha. No inventes instrumentos, valores ni mecanismos biológicos. Incluye «ejemplo didáctico conceptual».

### Pasos y comprobaciones

Usa el prompt en Illustration. Revisa las etiquetas y la dirección de las flechas, y prueba una herramienta del tutorial. El ejemplo no describe un protocolo experimental real.

[Ver el proceso completo](https://cdn.scifig.ai/images/media-kit/2026-10/videos/v4-illustration-tutorial.mp4)

## Un proceso didáctico de revisión de datos · FlowChart

### Entrada

Crea un proceso didáctico: recibir datos sintéticos → validar nombres de columnas y unidades → revisar valores ausentes → resumir → revisar gráfico → compartir. Si falla la validación, vuelve a la entrada. Etiqueta las ramas y conserva la revisión antes de compartir.

### Pasos y comprobaciones

Usa el texto en FlowChart. Revisa cada nodo, el bucle de validación y las etiquetas de decisión. Modifica un nodo en el editor y comprueba que las relaciones sigan coincidiendo con la entrada.

[Ver el proceso completo](https://cdn.scifig.ai/images/media-kit/2026-10/videos/v4-flowchart-tutorial.mp4)

Revisa el significado científico, las etiquetas y las fuentes antes de compartir. Las opciones de edición y exportación dependen del espacio y del proceso; los tutoriales muestran ejemplos concretos.
