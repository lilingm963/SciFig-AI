## 让想法、数据与研究流程清晰可视。

SciFig 将 Illustration、DataChart 和 FlowChart 汇集到一个科研表达平台。了解工作流程，跟做示例，查找可复用的公开资源。

[打开 SciFig](https://scifig.ai/zh/?ref=github-resources) · [查看全部教程](https://scifig.ai/zh/tutorials?ref=github-resources) · [官方素材库](docs/media-library.zh.md)

## 三个工作区

### Illustration

将描述和参考资料转为科研插图，再使用相应编辑工具完善结果。

[![Illustration 完整工作流程](assets/previews/illustration.jpg)](https://cdn.scifig.ai/images/media-kit/2026-10/videos/v4-illustration-tutorial.mp4)

[查看完整流程](https://cdn.scifig.ai/images/media-kit/2026-10/videos/v4-illustration-tutorial.mp4) · [查看全部教程](https://scifig.ai/zh/tutorials?ref=github-resources)

### DataChart

使用表格数据制作图表并调整呈现方式。请对照原始数据核对数值、单位、坐标轴与图例。

[![DataChart 完整工作流程](assets/previews/datachart.jpg)](https://cdn.scifig.ai/images/media-kit/2026-10/videos/v4-datachart-tutorial.mp4)

[查看完整流程](https://cdn.scifig.ai/images/media-kit/2026-10/videos/v4-datachart-tutorial.mp4) · [查看全部教程](https://scifig.ai/zh/tutorials?ref=github-resources)

### FlowChart

将研究过程与结构化流程可视化，再在编辑器中调整节点和关系。

[![FlowChart 完整工作流程](assets/previews/flowchart.jpg)](https://cdn.scifig.ai/images/media-kit/2026-10/videos/v4-flowchart-tutorial.mp4)

[查看完整流程](https://cdn.scifig.ai/images/media-kit/2026-10/videos/v4-flowchart-tutorial.mp4) · [查看全部教程](https://scifig.ai/zh/tutorials?ref=github-resources)

分享前请核对科学含义、标注与来源。编辑和导出选项因工作区与流程而异，教程展示了具体示例。

## 三个跟做示例

这些输入是合成教学示例，不是实验依据。教程预览展示的是独立的产品流程，并非由这些示例输入生成的结果。

## 公开资源

### 海报与演示模板

按印刷尺寸或汇报用途浏览 154 个 PPTX 文件。预览布局，使用前查看模板许可。

[海报与演示模板](https://github.com/scifig-ai/scientific-poster-and-presentation-templates)

### 科研绘图 Skill

在 Agent 中梳理图示结构与提示词。生成使用 Agent 可用的图像工具或已配置的图像 API；此 Skill 不调用 SciFig API。

[科研绘图 Skill](https://github.com/lilingm963/scifig-ai-scientific-figure-skill)

### 官方素材库

35 条成品视频、多语言素材包、字幕和产品预览。文件保留在官方 CDN，本仓库提供目录和使用说明。

[官方素材库](docs/media-library.zh.md)

## SciFig 的开发者

Alex Carter 是 SciFig 的创始人与独立开发者。他的公开作品包括平台、科研海报与演示模板、实用指南和这套资源。编辑标准与联系信息请查看关于我们页面。

[关于我们与编辑标准](https://scifig.ai/zh/about?ref=github-resources)

## 许可与使用

SciFig 是商业平台。本仓库是公开资源入口，不是产品源码。素材、模板和采用 MIT 许可的 Skill 各有独立条款，任何一项许可都不自动覆盖其他内容。

[媒体素材使用条款](https://scifig.ai/zh/media-kit?ref=github-resources#usage) · [MIT](https://github.com/lilingm963/scifig-ai-scientific-figure-skill/blob/main/LICENSE) · [海报与演示模板](https://github.com/scifig-ai/scientific-poster-and-presentation-templates/blob/main/LICENSE)
